# langchain-xai wraps xAI's Grok models (BaseChatOpenAI-compatible) behind
# LangChain's standard ChatModel interface. If this deployment is actually
# meant to call Groq's hosted gpt-oss-120b instead of xAI's Grok (the
# project brief named both, which point to two different providers — see

# `langchain-groq` and follow the instructions in model.py.
#
# langchain-core is intentionally NOT pinned to an exact version here: both
# langchain and langchain-xai pin their own compatible langchain-core range,
# and pip's resolver picks the version that satisfies both — pinning a
# third, independent version above was found (by actually running `pip
# install` during this project's construction) to create an unsatisfiable
# conflict. See docs/REVISION_LOG.md.

langchain-xai
